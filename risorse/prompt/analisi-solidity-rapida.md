# Prompt Solidity Security — Versione Rapida

Analizza questa funzione Solidity rispondendo in ordine:

1. Cosa fa?
2. Chi può chiamarla?
3. Quali input controlla il caller?
4. Può ricevere Ether?
5. Quale storage legge?
6. Quale storage modifica?
7. Fa external calls?
8. Quando il controllo passa fuori dal contratto?
9. Quali assunzioni sta facendo?
10. Cosa può andare storto?
11. Quali proprietà deve sempre rispettare?
12. Quali happy-path e negative test scriveresti in Foundry?
13. Vedi vulnerabilità certe o soltanto punti da approfondire?

Spiegami tutto come a uno studente principiante e non usare il nome di una vulnerabilità senza prima spiegare il meccanismo che la causa.
